# Combined Shieldstral dataset

Snapshot built from pinned upstream sources. **WildGuardMix is unavailable and not included.** BIPIA covers its accessible EmailQA, TableQA, and CodeQA contexts; WebQA and summarization are excluded because their source contexts are not distributed with BIPIA.

## Provenance and labels

Each row includes a fixed Shieldstral system prompt, an instruction/policy, a yes/no question, the document, and an assistant answer. Metadata retain task, source identifier, upstream split, revision, license, attribution, original label fields, and transformation details where applicable. BIPIA binary labels are generated by construction (original clean context versus inserted attack); they are not independently human-reviewed detector annotations.

## Splits and cleaning

- `input_records`: 51,755
- `document_groups`: 27,681
- `conflicting_example_keys`: 166
- `dropped_duplicates`: 7,569
- `dropped_split_overlap`: 809
- `dropped_conflicting_labels`: 390

Exact normalized-document groups are disjoint across output splits. Lower-priority overlapping rows are discarded, with original test > original validation > original train. Label conflicts are checked only after this holdout precedence, preserving a valid test label despite a conflicting training duplicate. Train-only groups receive a deterministic 5% validation assignment. NotInject remains exclusively in test.

Normalization covers Unicode NFKC, case folding, and whitespace. Semantic paraphrases and shared attack families are not deduplicated. BIPIA validation can share attack templates with training; its original train/test attack strings are checked for exact separation. Public evaluation exposure during original model training is unknown.

## Licenses and files

Source records retain individual license terms; TableQA/CodeQA adaptations retain CC BY-SA 4.0. See `../../THIRD_PARTY_NOTICES.md` and `upstream-notices/` for attribution, source licensing, and the deepset metadata discrepancy. `manifest.json` records exact source revisions, input checksums, output checksums, filtering statistics, and omissions.

Run `uv run shieldstral-unpack-data` to restore the checked-in `.jsonl.gz` files. The helper verifies each uncompressed output against the manifest. Data preparation has been checked; GPU training and tokenizer-length auditing have not been performed.
